# Sherlock Storytelling Map

An interactive Figma prototype that helps fans explore the London of BBC Sherlock. Users can discover Sherlock-related locations, plan a walking route, and unlock dialogue clips and soundtrack fragments when they arrive at each place. This was my practice-based MA dissertation project at King's College London.

This was an individual project. I was responsible for:

User research: designed a questionnaire and analysed 38 valid responses on fans' screen tourism habits
UX design: created personas, a user journey map and the information architecture
UI and prototyping: designed high-fidelity screens and an interactive prototype in Figma
Testing and iteration: ran user testing and redesigned the trip planning page so routes can sync to existing map apps
